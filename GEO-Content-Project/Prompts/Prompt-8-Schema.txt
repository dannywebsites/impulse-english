## WHY THIS MATTERS FOR GEO

Schema markup is the translation layer between your website and AI systems.

**Research findings:**
- GPT-4 accuracy improves from 16% to 54% with structured data
- LLMs grounded in knowledge graphs achieve 300% higher accuracy
- Pages with schema are 36% more likely to appear in AI summaries
- Microsoft confirmed at SMX Munich 2025: "Schema helps LLMs understand content"

**Critical point:** Each location page needs UNIQUE schema markup. Copy-pasting schema with only the address changed signals duplicate content.

---

## REQUIRED SCHEMA TYPES

Every service/location page should include these four schema types:

### 1. LocalBusiness (or specific subtype)
Tells AI: "This is a real business in a specific location"
- Use specific type when applicable (Plumber, Electrician, Dentist, etc.)
- Must include geo coordinates
- Must include areaServed

### 2. Service
Tells AI: "This is the specific service offered"
- Links to the LocalBusiness
- Includes pricing information
- Describes what the service includes

### 3. FAQPage
Tells AI: "Here are questions this page answers"
- Highest citation probability of all schema types
- Must match visible FAQ content on page
- Each Q&A should be location-specific

### 4. AggregateRating
Tells AI: "This business has verified social proof"
- Include review count
- Include rating value
- Link to review source

## SCHEMA SPECIFICATIONS

### LocalBusiness Schema

```json
{
  "@context": "https://schema.org",
  "@type": "[Specific Business Type]",
  "@id": "[Page URL]#business",
  "name": "[Business Name - Location]",
  "image": "[Image URL]",
  "url": "[Page URL]",
  "telephone": "[Phone]",
  "priceRange": "[$ to $$$$]",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "[Street Address]",
    "addressLocality": "[City]",
    "addressRegion": "[State]",
    "postalCode": "[ZIP]",
    "addressCountry": "US"
  },
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": [Latitude],
    "longitude": [Longitude]
  },
  "areaServed": [
    {"@type": "Neighborhood", "name": "[Neighborhood 1]"},
    {"@type": "Neighborhood", "name": "[Neighborhood 2]"},
    {"@type": "Neighborhood", "name": "[Neighborhood 3]"}
  ],
  "openingHoursSpecification": {
    "@type": "OpeningHoursSpecification",
    "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"],
    "opens": "[Open Time]",
    "closes": "[Close Time]"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "[Rating]",
    "reviewCount": "[Review Count]",
    "bestRating": "5"
  },
  "sameAs": [
    "[Yelp URL]",
    "[Facebook URL]",
    "[LinkedIn URL]"
  ]
}
```

### Service Schema

```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "@id": "[Page URL]#service",
  "name": "[Service Name] in [Location]",
  "description": "[Service description - 1-2 sentences]",
  "provider": {
    "@id": "[Page URL]#business"
  },
  "areaServed": {
    "@type": "City",
    "name": "[City, State]"
  },
  "offers": {
    "@type": "Offer",
    "price": "[Starting Price]",
    "priceCurrency": "USD",
    "priceSpecification": {
      "@type": "PriceSpecification",
      "price": "[Starting Price]",
      "priceCurrency": "USD",
      "minPrice": "[Min Price]",
      "maxPrice": "[Max Price]"
    }
  }
}
```

### FAQPage Schema

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "[Question 1]",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "[Answer 1]"
      }
    },
    {
      "@type": "Question",
      "name": "[Question 2]",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "[Answer 2]"
      }
    }
  ]
}
```

## INPUT CHECKLIST

Before generating, verify you have from Business-Information.txt:

### For LocalBusiness:
- [ ] Business name
- [ ] Business type (for schema @type)
- [ ] Street address
- [ ] City, State, ZIP
- [ ] Phone number
- [ ] Website URL
- [ ] Page URL (this specific page)
- [ ] Latitude and longitude
- [ ] Neighborhoods served (for areaServed)
- [ ] Hours of operation
- [ ] Price range ($, $$, $$$, $$$$)
- [ ] Rating and review count
- [ ] Social profile URLs

### For Service:
- [ ] Service name
- [ ] Service description
- [ ] Starting price
- [ ] Price range (min/max)

### For FAQPage:
- [ ] At least 3 FAQ questions
- [ ] Answers for each (matching visible page content)

---

## QUALITY CHECK

Before delivering, verify:
- [ ] JSON syntax is valid (no trailing commas, proper quotes)
- [ ] @id values are unique and use the page URL
- [ ] Phone number is in international format (+1-XXX-XXX-XXXX)
- [ ] Geo coordinates are accurate for this location
- [ ] areaServed lists specific neighborhoods (not just city)
- [ ] FAQ questions match the visible content on the page
- [ ] All required fields are populated
- [ ] Price values are numbers (not strings with $)

---

## WHAT MUST BE UNIQUE PER LOCATION

When creating schema for multiple location pages, these fields MUST be different:

- [ ] @id (include page URL)
- [ ] name (include location)
- [ ] url (page-specific URL)
- [ ] telephone (if different per location)
- [ ] address (completely different)
- [ ] geo coordinates (different lat/long)
- [ ] areaServed (different neighborhoods)
- [ ] aggregateRating (if tracked per location)
- [ ] FAQ questions and answers (location-specific)

## COMMON MISTAKES

**Invalid JSON:**
- Trailing commas after last item in arrays
- Missing quotes around string values
- Using single quotes instead of double quotes

**Missing Required Fields:**
- LocalBusiness without address
- Service without provider link
- FAQPage with empty answers

**Copy-Paste Errors:**
- Same @id across multiple pages
- Same geo coordinates for different locations
- Generic FAQ answers that don't match page content

**Incorrect Data Types:**
- Price as "$89" instead of "89"
- Rating as string instead of number
- Coordinates as strings instead of numbers
