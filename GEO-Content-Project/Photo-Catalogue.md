## ⚠️ Orientation problem — read before using any of these

**18 of 21 are PORTRAIT (3024×4032).** Only 3 landscape, 2 square.

The existing barrio pages use **full-bleed landscape hero images**. Dropping a portrait photo
into a wide hero box and `object-cover`-ing it crops out ~60% of the frame and reads as
"zoomed"; `object-fill` distorts faces. Neither is acceptable.

**Rules for this set:**
- Heroes must come from the 3 landscape + 2 square shots only.
- Portraits go in portrait-shaped or square containers: side-by-side text/image splits,
  3-up card grids, or a masonry gallery. Never a full-width band.
- Faces are near the frame edges in several shots (IMG_8724, IMG_8741) — set
  `object-position` deliberately, don't accept the default centre crop.

alt text across the set. (Danny: are there more named classrooms than these two?)
