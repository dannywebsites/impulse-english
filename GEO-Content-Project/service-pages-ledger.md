## Notes and corrections

**2026-08-03 — the plan's baseline estimate was optimistic.** The plan quoted ≈47/100.
That was the best single page (Adultos). Measured site-wide across all seven is **42**.
The gap to the 90 gate is 48 points, not 43.

**2026-08-03 — bug found in `geo-audit.py`, fixed in row 01.** `find_astro_for()` globbed
`src/pages/*.astro`, top level only. Every page in a subdirectory resolved to `None`, and a
`None` wrapper silently scores Title Tag and all four schema rows as **0**. The barrio pages
all live at the top level, so the bug never showed. Any earlier service-page score produced by
this script before row 01 is wrong and should be discarded.

Also fixed in the same commit:
- `find_astro_for()` now matches on a word boundary; the bare substring test would match a
  wrapper that merely mentioned the component name.
- `dist_of()` now reads the wrapper's `canonical` prop instead of guessing the slug from the
  component filename. The guess works for barrios but not services — `ParticularsPage.tsx`
  serves `/cursos-ingles/particulares/` and `CursosOverviewPage.tsx` serves `/cursos-ingles/`,
  neither derivable from the filename. The old slug guess is kept as a fallback so barrio
  scoring cannot move.
